*Product is still in development. This is work in progress release.

Spriteformer is a level and image editor written in C and uses SDL to achieve great performance on low end machines. Its goal is to help designing levels and draw sprites in a simple and intuitive way. You can edit images and immediately try your level. Spriteformer is not meant to be a game engine, instead it help in the process of coding games in an old school way.

The top menu consists of: 
- Play View. Here you can try your level
- Level Editor. Here you design your level with objects
- Object Editor. Here you mark the passable mask of the sprite.
- Speech Editor. Add speech to objects when you are nearby
- Sprite Editor. Draw and edit sprites
